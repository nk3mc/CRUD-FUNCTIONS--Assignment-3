# TaskBuddy - Web and Scripting Assignment 3

TaskBuddy is a simple web application that allows users to manage daily tasks. Users can add tasks, view tasks, mark tasks as completed, edit tasks, and delete tasks. This assignment demonstrates working CRUD operations using Node.js, Express, and MongoDB.

---

## Features
- Add a new task
- View all tasks
- Edit and update task information
- Mark a task as complete
- Delete a task with a confirmation message
- Responsive and user-friendly design
- Custom CSS styling created by me (located in /public/styles.css)
- MongoDB connection secured using .env file

---

## Technologies Used
- Node.js and Express.js (Backend)
- MongoDB Atlas with Mongoose
- EJS Template Engine for Rendering Views
- Bootstrap + Custom CSS for Styling

---

## Security Requirements
I used a `.env` file to secure my MongoDB connection string.  
The `.env` file is included in `.gitignore` so it does not get uploaded to GitHub.

---

## How to Run
1. Install dependencies using: `npm install`
2. Start the server using: `npm start`
3. Open browser and go to: `http://localhost:4000`

---

## CRUD Operations Included
- Create: Add new task form
- Read: Display all tasks page
- Update: Edit task modal
- Delete: Delete button with confirmation
- Complete: Set task as complete
